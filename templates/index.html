Score de pertinence & contrat IA

Formule

Le porteur ne saisit pas le score. L’IA attribue les notes qualitatives 1–5 ; la rentabilité est déduite des montants ; le 0–100 est la somme pondérée.

DimensionPoidsConstruction
Rentabilité25 %ROI + délai de retour + CA an 3 / investissement
Alignement stratégique20 %Priorité Groupe (65 %) + impact branches (35 %)
Maîtrise des risques15 %Inverse des risques technique, humain, réglementaire
Impact opérationnel15 %Impact branches − pénalité de complexité
Impact social / environnemental15 %Social 55 % + environnemental 45 %
Faisabilité technique10 %Maturité technique + maturité porteur − complexité

Seuils Codir : ≥ 75 GO prioritaire · 60–74 GO sous conditions · 45–59 réviser · < 45 NO-GO ou report.

Contrat d’utilisation de l’IA

  • Sortie JSON uniquement, style neutre, aucun chiffre inventé.
  • Moteur grok si XAI_API_KEY, sinon claude si ANTHROPIC_API_KEY, sinon repli déterministe MySQL. Forçage : LLM_PROVIDER=grok|claude|auto.
  • Cinq prompts métier : évaluation du score, analyse, business plan, scénarios, note Codir + dialogue.
  • Chaque génération est historisée dans la table generations.
